ROYAL WEDDING PLANNER — ENHANCED UI DEMO

Files
- index.html: Home page
- about.html: Brand story, values and planning approach
- services.html: Detailed service catalogue and planning workflow
- venues.html: Dedicated Mehndi, Baraat, Walima and Mayun hall showcase
- packages.html: Sample package cards, comparison matrix and per-head event rates
- booking.html: Event-by-event guest count and live estimated bill calculator
- gallery.html: Filterable event inspiration gallery
- testimonials.html: Sample couple stories and testimonials
- contact.html: Contact inquiry form and inquiry preparation guide
- faq.html: Planning and demo functionality FAQs
- account.html: Frontend-only login/register concept

How to run
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server (or open the file directly in a browser).

Important
- This project is HTML, CSS and JavaScript only. No backend, SQL Server or database is connected.
- Booking estimates and comments are calculated/rendered in the browser only. They are not saved or sent.
- Login and registration are visual demos only; authentication is not implemented.
- Package prices, per-head rates, testimonials, venue names and contact details are sample UI content. Confirm/edit them before any real client use.
- Photos and Google Fonts load from external URLs and require an internet connection.
